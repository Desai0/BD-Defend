# Как сделать шесть скриншотов

Из корня репозитория запусти:

```bash
rtk proxy python -X utf8 lesson_03/workflow.py --reset
```

MongoDB должна быть запущена, PyMongo установлен — команды есть в
[README.md](../README.md). На каждой остановке снимай терминал так,
чтобы были видны номер этапа и его результат. Затем нажимай Enter.
Кадры сохраняй прямо в `lesson_03/screens/`, без изменения имён.

| Шаг | Имя файла | Что должно попасть на снимок |
|---|---|---|
| 1 | `01-program-start.png` | Команда запуска, сообщение о подключении, версии Python и MongoDB, названия коллекций |
| 2 | `02-products-created.png` | Загрузка `shop.products` и `sandbox.products`: по 21 товару |
| 3 | `03-catalog-result.png` | Первая страница: 5 из 21, артикулы, названия, цены и рейтинги; первый товар — MacBook Air 13 за 114990 |
| 4 | `04-search-result.png` | Фильтр по категории «ноутбуки», 5 найденных товаров и пустая страница 9: 0 из 5 |
| 5 | `05-update-or-delete-result.png` | Приёмка: остатки +5/+12/+3, 2 новые позиции, 1 удалённая позиция, 5 аксессуаров, итог 22 товара |
| 6 | `06-database-check.png` | Проверка реальных данных в MongoDB: остатки 5/12/3, 22 позиции, сохранённый эталонный каталог и итог 12 из 12 |

Терминал разрешён заданием для подтверждения результатов. Если предпочитаешь
Compass, для последнего кадра открой `sandbox.products`, нажми Refresh и покажи
22 документа; у товара `SKU-NB-001` раскрой `qty_total: 5`.
Подключение: `mongodb://localhost:27017/` (**data-platform local**).

Если нужный вывод не помещается, увеличь высоту окна или немного уменьши шрифт.
После последнего кадра Enter завершает workflow. Не запускай отдельно
`solution.py` между кадрами: это ещё раз прибавит поставку.

При ошибке или прерывании начни заново той же командой с `--reset`.
Для повторной проверки без изменения данных используй:

```bash
rtk proxy python -X utf8 lesson_03/check.py
```

Ссылки на эти шесть имён уже подготовлены в [отчёте](../homework_03.md).
Старые кадры находятся в `archive-2026-09-27/`; в новый отчёт они не подставляются.
